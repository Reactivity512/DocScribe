## Расшифровка hallucination_free_rate=0.526
Guard считает "unknown identifier" любое слово из черновика, отсутствующее в allow-list.
Для qwen2.5-coder:3b это в основном ЛОЖНЫЕ срабатывания:
- обычные слова, распознанные как идентификаторы (`requires-python` — конфиг-ключ, корректный);
- generic-параметры из кода вызывающей стороны (`page_size`, `api_token` — аргументы, не символы публичного API).
Реальных галлюцинаций API (несуществующие классы/функции demopkg) в отчётах дропов нет.
Решение лидера (2026-10-06): **гард оставляем как есть** — консервативный bias безопасен для MVP,
утечка качестваdocumentation ловится HITL-ревью лида.
